If something found in one case would hold across cases, state it as a rule and cite the recordings that show it. If you cannot show it, leave it out.

Cite every claim by the run and call that shows it, in the form "run 001 call 4". A claim with no citation will be discarded.

Give the skill a short lowercase name made of letters, digits and hyphens, and a one-sentence description that tells an agent when to load it. Put the guide in the body. Put long lists of results in reference files and name them in the body. List the runs and calls you drew on as evidence.
