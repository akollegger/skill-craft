# Procedures

## Procedure

- Begin an unfamiliar crafting task by running the craft help operation to discover the available interface before committing materials.  
  _evidence: 5abd8179-d362-442c-ae36-31a248d58d97, 3ba0810c-f27e-4664-a40a-3a70fd973798_
- Use inventory checks and table-placement operations to inspect or prepare the crafting state before invoking the irreversible craft operation.  
  _evidence: c528a938-d1f1-44ed-b60e-51dba4c3ce0a, 9d930652-39ca-40c2-8da4-887099063b93, c74ddb50-a900-4ebf-9233-231e56e57f2a, 70768165-d4c5-4002-b9b3-feab8e8b6572_
- Invoke the craft operation only after the table is prepared, then check inventory to confirm that the target object is being held.  
  _evidence: ff666652-6098-4adc-a0ec-57230524d0e7, 9881401f-ee83-4c24-9ba3-3c13e2aa16ba, 87dd8d70-d58e-42d8-b184-71eaaf74fc70, d5850e73-de2a-479a-b539-029b7f9bc716_

## Success criteria

- Treat the task as complete only when inventory verification confirms that one stone_pickaxe is held; report that result briefly and stop.
