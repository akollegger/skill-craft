# Procedures

## Procedure

- Start an unfamiliar crafting task by invoking the craft help tool to learn the available operations.  
  _evidence: d39597e5-6334-4c3b-83d2-5d68c4984387, 82420531-d3d8-4123-aac3-8c8cdb8c4edf_
- Check inventory during the crafting workflow to determine whether the requested item is already being held or has been produced.  
  _evidence: 30c62eb8-6a2f-4aa0-bb9f-1beb8fa31b19, cc354b48-0b24-4ca7-94f0-d6152fe8a555_
- Use the place operation to prepare the crafting table, then invoke craft only after the table state is ready.  
  _evidence: f16df5b8-a2e3-41fa-b5c3-7a145477adfa, 3c0bb8b6-bdd9-42dc-aa96-8a5d53eca82a, ad51197f-6638-4c30-9f02-54a332558409, d6c1d96b-f72f-4266-8e1a-57df57995ba4_

## Success criteria

- Finish only after inventory confirms that the requested target item is held, then report completion briefly and stop.
